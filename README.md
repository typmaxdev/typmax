# Typmax

Typmax is a PCB design editor for designing printed circuit boards.

**[typmax.com](https://typmax.com)**

This is the place to report problems, suggest features and ask for help.

## Feedback

- **[Report a bug](../../issues/new?template=bug.yml)** — something isn't working as expected.
- **[Request a feature](../../issues/new?template=feature.yml)** — an improvement or something new.
- **[Ask a question](../../issues/new?template=question.yml)** — need help, or not sure it's a bug? Ask.

Not sure what to include? Just tell us what happened. Screenshots are welcome. Please don't attach board files unless you're happy for them to be public.

More in [SUPPORT.md](SUPPORT.md). Everyone here follows our [code of conduct](CODE_OF_CONDUCT.md).

## Security

Found a security vulnerability? Please report it privately, not in a public issue. See [SECURITY.md](SECURITY.md).

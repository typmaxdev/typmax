# Security

## Report a vulnerability privately

**Never report a security problem in a public issue.** Report it privately:

1. Open the [Security tab](https://github.com/typmaxdev/typmax/security) of this repository.
2. Click **Report a vulnerability** and fill in the form.

If you can't use the form, email hello@typmax.com.

Only you and the maintainers can see the report.

## What to include

- The Typmax version (Help › About shows it).
- What an attacker can do, and the steps to show it.
- Your browser or OS.

Don't attach a real board. If a file is needed to show the problem, make a small one that holds nothing private.

## What happens next

We aim to reply within 5 working days, keep you told while we fix it, and credit you in the advisory if you want.

## Supported versions

Security fixes go into the latest release only. Update to it to get them.
